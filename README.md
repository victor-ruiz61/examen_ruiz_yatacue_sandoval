## Descripción

DEV presenta destinos turísticos, servicios y opciones de viaje además el sitio permite conocer la agencia y completar un formulario
de contacto de demostración para una prueba completa

## Páginas

- index.html: presentación, destinos, servicios y enlace a video.
- nosotros.html: historia, misión, visión y valores de la agencia.
- contacto.html: formulario e información de contacto.

## Tecnologías utilizadas

- HTML5 para la estructura y el contenido
- CSS para el diseño, los colores y las animaciones
- Flexbox para la navegación, el footer y las alineaciones
- CSS Grid para las tarjetas y la distribución del contenido
- Git y GitHub para el control de versiones, solucion de errores y el trabajo en equipo


## Cómo visualizar el sitio
1. Clonar o descargar el repositorio.
2. Abrir index.html en un navegador.
3. Utilizar el menú para navegar entre Inicio, Nosotros y Contacto.
También se puede abrir el proyecto en Visual Studio Code
y visualizarlo con la extensión Live Server.
